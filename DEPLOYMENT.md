# 🚀 Развертывание приложения в продакшен

## 📋 Быстрый старт

### 1. Сборка проекта
```bash
npm run build
```

### 2. Проверка сборки
```bash
npm run preview
```

### 3. Развертывание
Скопируйте содержимое папки `dist/` на ваш веб-сервер.

## 🔧 Настройка для продакшена

### 1. Переменные окружения
Создайте файл `.env.production`:
```env
VITE_FIREBASE_API_KEY=ваш-api-key
VITE_FIREBASE_AUTH_DOMAIN=ваш-проект.firebaseapp.com
VITE_FIREBASE_PROJECT_ID=ваш-проект-id
VITE_FIREBASE_STORAGE_BUCKET=ваш-проект.appspot.com
VITE_FIREBASE_MESSAGING_SENDER_ID=ваш-sender-id
VITE_FIREBASE_APP_ID=ваш-app-id
VITE_FIREBASE_MEASUREMENT_ID=ваш-measurement-id
```

### 2. Настройка Firebase
- Убедитесь, что домен добавлен в **Authorized domains** в Firebase Console
- Настройте правила Firestore для продакшена
- Проверьте настройки аутентификации

### 3. Оптимизация
- ✅ **Код разделен на чанки** - для быстрой загрузки
- ✅ **Консоль очищена** - удалены console.log в продакшене
- ✅ **Минификация включена** - код сжат
- ✅ **PWA готово** - работает офлайн

## 📱 PWA функции

### Установка на устройство
- Откройте сайт в браузере
- Нажмите "Установить приложение" (если доступно)
- Или через меню браузера → "Установить приложение"

### Офлайн работа
- Приложение кэширует основные ресурсы
- Работает без интернета (кроме Firebase операций)
- Автоматически обновляется при изменении кода

## 🚨 Важные моменты

### Безопасность:
- Все пароли хранятся в localStorage (небезопасно для продакшена)
- Рекомендуется использовать Firebase Authentication
- Настройте правила Firestore для ограничения доступа

### Производительность:
- Первая загрузка может быть медленной из-за размера бандла
- Используйте CDN для статических файлов
- Настройте кэширование на сервере

### Мониторинг:
- Настройте Firebase Analytics
- Добавьте логирование ошибок
- Мониторьте производительность

## 📞 Поддержка

При возникновении проблем:
1. Проверьте консоль браузера на ошибки
2. Убедитесь в правильности Firebase конфигурации
3. Проверьте доступность по HTTPS
4. Проверьте правила Firestore
